# نظام الألوان الاحترافي — Research Search Platform

## نظرة عامة
تم تطبيق نظام لوني متكامل بناءً على علم الألوان والتصميم الحديث لضمان:
- **التناغم البصري**: جميع الألوان متناسقة وتعكس هوية البحث العلمي

## مبادئ التطبيق

### 1. **التدرج اللوني (Gradients)**
استخدام تدرجات لطيفة من الأزرق للحصول على عمق بصري:
```css
background: linear-gradient(135deg, #0B3D91 0%, #071E4A 100%);
```

### 2. **التباين والوضوح**
- النصوص الداكنة على الخلفيات الفاتحة
- النصوص البيضاء على الخلفيات الداكنة
- نسبة تباين لا تقل عن 4.5:1 (WCAG AA)

### 3. **التفاعلات (Interactions)**
- **Hover**: تفتيح اللون أو إضافة ظل
- **Active**: تعميق اللون أو تطبيق تحويل بصري
- **Disabled**: تخفيف اللون وتقليل الشفافية

### 4. **Shadows للعمق**
```css
/* خفيف */
box-shadow: 0 2px 8px rgba(11,26,43,0.04);

/* متوسط */
box-shadow: 0 8px 24px rgba(11,26,43,0.08);

/* قوي */
box-shadow: 0 20px 50px rgba(0,0,0,0.7);
```
